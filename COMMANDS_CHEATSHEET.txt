COMMON ISSUES & FIXES
================================================================================

"java is not recognized"
  → Install Java: https://www.oracle.com/java/technologies/downloads/

"mvn is not recognized"
  → Install Maven: https://maven.apache.org/download.cgi
  → Add to PATH (see WINDOWS_RUN_GUIDE.md)

"Port 8888 already in use"
  → Change port in EmergencySystemLauncher.java (line: setParameter(Profile.MAIN_PORT, "8889"))

"No incidents generated"
  → Wait 30+ seconds (generation is probabilistic)
  → Edit SensorAgent.java: detectionProbability = 0.8

"BUILD FAILED"
  → Check: java -version (need 11+)
  → Check: mvn --version (need 3.6+)
  → Internet connection required (first build downloads ~100MB)

"No reports found"
  → Check logs directory exists: mkdir logs
  → Run system for 30+ seconds before checking
